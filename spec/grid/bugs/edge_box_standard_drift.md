# 边缘框阈值随分辨率漂移

## 现象
顶部/底部/左右边缘截断商品：有人标、有人不标；模型在边缘层整排漏检或顶边多标细条假框。

## 根因
规则里的"可见宽度/高度阈值"用原图像素表述，不同分辨率/裁剪后标准不一致；且规则只写"边缘"
没有写"可见物理结构可判断才保留"。

## 证据
- 沙河 80 人工清洗 GT 1794→1901 框（9/3）；
- conf=0.25 badcase：FN 中 60/98 在上下边缘层；FP 中 112/281 贴上下边缘、75% FP conf<0.5；
- 852 清洗 73 处真实改动（+330/−223）。

## 处置
- 阈值统一换算到 imgsz=800 坐标系（200px→对应归一化值），避免原图分辨率漂移；
- 标注规则改为"能判断物理结构且达到阈值→保留；只剩残框→删；不随模型预测决定"；
- 增加 edge_complete / edge_truncated 属性分别评估。
