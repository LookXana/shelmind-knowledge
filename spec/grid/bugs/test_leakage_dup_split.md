# 重复图跨 split 泄漏

## 现象
训练/验证/测试之间出现同图（不同命名或重复拷贝），评估数字虚高；简单合并数据后模型"提升"
其实来自泄漏。

## 根因
- 简单合并 3345+1145+旧 s2000 未去重：发现 16 组重复图，其中 2 组跨 train/val/test；
- 切分未按店+日期/相机前缀整组做。

## 证据
- balanced 修正线排查（2026-08-27~28 报告 §3.1）；
- dedup_check.py / 图像哈希去重结果。

## 处置
- 重建质量数据集时：去重 + 按来源分层 + 固定 seed 切分；
- 落地训练前门禁 `check_train_test_disjoint.py`（stem 级比对，重叠阻止训练）；
- 公平对比另查"见过原图"重叠红利（test256 的 D vs E 教训）。

## 预防
- 新增数据强制保留来源前缀；
- 每个训练源记录"与冻结 test 重叠多少"，做成训练前检查项。
