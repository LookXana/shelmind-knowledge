# 评测目录复用导致标签累积

## 现象
Optuna/E8 系列结果失真：eval 目录被反复复用（exist_ok），上一轮预测/标签文件残留累积，
新结果与旧文件混在一起。

## 根因
评测脚本对输出目录使用"存在即复用"，没有强制独立目录。

## 证据
- E8 Optuna 复盘（2026-08-28 后）；training_failure_retrospective.md。

## 处置
- 评测输出每次用独立目录，禁止 exist_ok 复用；
- 失败保留原目录排查，换新 `--run-dir` 重跑。

## 预防
- run 脚本默认检查目标目录不存在才允许启动；
- 汇总阶段只读一次目录、校验文件计数与时间戳。
