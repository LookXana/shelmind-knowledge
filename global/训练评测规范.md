# 检测任务训练评测规范（跨任务通用）

> 适用范围：目标检测类任务（当前实例：grid）。GRPO/蒸馏类任务的规范另行文件。
> 来源：棚格项目多次踩坑后沉淀（2026-09-07 蒸馏）。

## 1. 指标口径（对数字前先对齐，缺一不可）

- **TP/FP/FN**：预测框与 GT 做匹配后，匹配上的真框=TP，预测了但 GT 没有=FP，GT 有但没预测到=FN；
- **match IoU**：判 TP 的匹配阈值，检测项目固定 0.5；
- **conf**：过滤预测的置信度阈值。conf 越低 Recall 高/FP 多，越高 Precision 高/FP 少；
  **不同 conf 的数字不能直接比**（0.25 与 0.45 之间常见 +0.01~0.02 F1 差异）；
- **NMS IoU**：预测阶段抑制重叠框的阈值。调低会抑制相邻/嵌套框；
  对"相邻/嵌套合法重叠"的结构，NMS 调低会伤 mAP（如棚格 0.45 复评全线下滑）；
- **mAP50 / mAP50-95**：对全部置信度积分，与 conf 无关；mAP75 对定位更敏感，
  "mAP50 涨但 mAP75 不涨"=只改善召回、没改善定位；
- **P/R/F1 与 mAP 分开汇报**，各自标注协议。

## 2. 固定测试集纪律

- 测试集一旦冻结不可改，跨版本只比同口径固定 test；
- 切分按"店+日期/相机前缀/批次"整组切，禁止扁平全量直接当 train；
- 混合训练前必须跨集去重（md5 + stem + 图像哈希），防止同图横跨 train/test；
- 训练前跑泄漏门禁：train 源 vs 冻结 test 的 stem 级比对，重叠直接阻止；
- 新测试集上线前，先给旧模型（baseline）补同口径数字。

## 3. 选模规则

- 选模必须带"保护线"：老域/主域回退阈值（如 ≤0.01），不能只看综合指标；
- 业务加权分要提前定义并写明权重；加权分与保护线同时满足才算候选；
- 对比用 `best.pt`，不用 `last.pt`；
- 公平对比前提：测试集与训练集无原图/同前缀重叠，否则数字虚高（见过原图=重叠红利）。

## 4. 常见误区（速查）

- conf=0.001 导出的框数会数倍于 GT，badcase 全失真；归因分析也要固定 conf；
- 训练/评测阶段有两个 IoU（NMS IoU、match IoU），写脚本时必须分开参数并落盘记录；
- 只调推理阈值压 FP 不等于定位变好，看 mAP75/边缘框 IoU；
- 数据质量/标注一致性/配比/泄漏对精度的贡献通常大于超参（数据优先）。
